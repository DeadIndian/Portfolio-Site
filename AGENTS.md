# Portfolio visual work

- The owner rejected the miniature workshop and its 3D style on 3 October 2026.
- Before implementing a new visual direction in the portfolio, make a runnable
  standalone HTML demo and show it to the owner. Wait for an explicit visual
  choice or approval before integrating that direction into the application.
- Approval of a written concept is not approval of its rendered appearance.
- Current experiments live in `design-demos/` on
  `deadindian/design/html-directions`. They are visual studies, not a replacement
  production site. Preserve the existing personal accounts and professional app.
- The current demo is the six-world journey requested on 5 October: Minecraft,
  One Piece, Iron Man/JARVIS, Linux, community, and an open ending. It replaces
  the old three alternatives. Read `design-demos/REVIEW.md` for the checkpoint
  and `design-demos/README.md` to run it and repeat the checks.
- Keep source, assets, screenshots, logs, and browser profiles on persistent disk.
  Use `.workshop/` for local review artifacts; do not use `/tmp` or `/var/tmp`.
- Commit and push completed reviewable milestones to the feature branch.
